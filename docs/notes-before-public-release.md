# Notes before public release

This repo currently includes recovered code and a recovered `pifm` binary from an old working Raspberry Pi image.

Before making the repository public:

1. Check the license and attribution for the original Pirate Radio / Make Magazine code.
2. Check the license/source for the bundled `pifm` binary.
3. Decide whether the binary should be committed, replaced with source build instructions, or stored as a release asset.
4. Do not commit the full music library.
5. Do not commit private/local `song_attributes.csv` unless intentionally publishing song metadata.
