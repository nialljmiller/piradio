# RF safety and legal note

This project can generate an FM radio signal using a Raspberry Pi.

Radio transmission rules vary by country and region. Check your local regulations before transmitting.

General safety guidance:

- Use this for tiny-range testing and experimentation only.
- Do not attach a large antenna.
- Do not use an amplifier.
- Do not interfere with licensed radio stations.
- Choose an unused local frequency.
- Stop transmitting if you notice interference.
- Keep tests short while developing.

This project is intended as a software recovery, maker, and educational project, not as encouragement to operate an unlawful broadcast station.
